Frequently Asked Questions

Common questions about rotating PDF files.

Can I rotate only one PDF page?

Yes. Choose Current Page Only and rotate the selected page.

Can I rotate all pages at once?

Yes. Select All Pages before using the rotate buttons.

Can different pages have different rotations?

Yes. Select Current Page Only, navigate through the PDF and rotate each page independently.

Will the rotation remain after download?

Yes. The selected rotations are saved into the downloaded PDF.
