Frequently Asked Questions

Common questions about using the Split PDF tool.

Is QuickFile Split PDF free to use?

Yes. The Split PDF tool is free to use for everyday PDF merging tasks.

Are my PDF files uploaded to a server?

For this Split PDF tool, the selected files are processed in your browser using client-side PDF processing. The files are not intentionally uploaded to our server.

How many PDF files can I merge?

You can select multiple PDF files. The practical limit depends on your device memory, browser and the size of the selected PDF files.

Does Split PDF work on mobile devices?

Yes. The tool is designed to work on modern mobile, tablet and desktop browsers.

Will merging PDFs reduce document quality?

The tool combines the existing PDF pages into one document. It does not intentionally compress the page content during the merge process.
